# UXterity - AI-Powered Design Agency Website

A modern, responsive website for UXterity, an AI-powered design agency specializing in UX Design, Frontend Development, and AI Applications.

## Features

- Modern, responsive design with dark mode
- Interactive animations using Framer Motion
- AI-powered design services showcase
- Portfolio section with hover effects
- Contact form with modern styling
- Mobile-friendly navigation

## Tech Stack

- Next.js 14
- TypeScript
- Tailwind CSS
- Framer Motion
- React

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/yourusername/uxterity.git
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
